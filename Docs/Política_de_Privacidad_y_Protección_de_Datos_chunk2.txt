6. Conservación de los datos Los datos se conservan únicamente por el tiempo necesario para cumplir con:  Obligaciones legales y regulatorias.  Procesos operativos y financieros.  Requerimientos de auditoría. Una vez cumplida la finalidad, los datos se eliminan o anonimizan. 7. Transferencia de datos Podemos compartir datos con:  Autoridades regulatorias.  Proveedores tecnológicos certificados.  Socios financieros autorizados. Nunca vendemos información personal a terceros. 8. Actualización de esta política Esta política puede actualizarse para reflejar cambios regulatorios o mejoras internas. Los usuarios serán notificados cuando se realicen modificaciones relevantes. 9.
